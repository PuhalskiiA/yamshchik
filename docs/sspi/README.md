# СППИ, 3-й семестр

Материалы по дисциплине «Современные проблемы ПИ». Работа ведётся в ветке `SSPI`, решения — в `BACKLOG.md` (R-54…R-57).

## Что сдаётся

**Курсовой проект (зачёт с оценкой):**

1. Оценка качества и производительности программного продукта — инструменты, скриншоты кода обращения к ним
   и скриншоты результатов, описание результатов.
2. AI-агент: описание инструмента, сгенерированный им код с комментариями, сравнение своего кода с кодом ИИ.
3. Приложение — исследования по СППР из практики.

На зачёте отчёт по пунктам 1 и 2 комментируется устно.

**Практика (зачёт):** СППР для выбора инструментария разработки и сопровождения — тестовый пример,
три свои ситуации выбора (не меньше 3 вариантов и 3 БО, веса БО в сумме 1, таблица оценок),
по три исследования на каждую с изменением данных и выводом после каждого «почему и за счёт чего»; код СППР в отчёте.
Какую СППР применять — уточняется у преподавателя (BACKLOG, «Отложено»).

## Оценка качества

Профиль Maven `sspi` добавляет SpotBugs, PMD (набор правил `quickstart`) и сканер SonarQube;
обычная сборка и CI его не используют.

```bash
./mvnw -Psspi verify
```

| Отчёт | Где |
|---|---|
| Покрытие (JaCoCo) | `target/site/jacoco/index.html` |
| SpotBugs | `target/reports/spotbugs.html`; интерактивно — `./mvnw -Psspi spotbugs:gui` |
| PMD | `target/reports/pmd.html` |

SonarQube:

```bash
docker compose -f docs/sspi/compose.sonar.yaml up -d --wait   # http://localhost:9002, admin / admin
./mvnw -Psspi verify sonar:sonar -Dsonar.token=<токен из My Account → Security>
```

Остановить: `docker compose -f docs/sspi/compose.sonar.yaml down` (с данными — `down -v`).

## Оценка производительности

Окружение и приложение — как в корневом `README.md`, затем нагрузочный тест k6 (до 50 виртуальных пользователей, 3 минуты):

```bash
docker run --rm -i -v "$PWD/docs/sspi/k6:/scripts" grafana/k6:2.3.0 run /scripts/submit-email.js
```

Пороги: ошибок меньше 1 %, 95-й перцентиль ответа меньше 500 мс. Метрики сервиса во время прогона —
`http://localhost:8080/actuator/prometheus` (`yamshchik_emails_accepted_total`, `yamshchik_emails_delivery_time_seconds`).
